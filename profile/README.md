<h3 align="center">We ship finished software.</h3>
<p align="center">One drop at a time.</p>

---

**Mustang** is a small engineering group.

Each release is a standalone piece of software with one job, its own repository, and a number.

It runs on infrastructure you control whenever possible.

The useful product is free. Paying supports the work; it does not unlock it.

## Drops

| Drop | |
| --- | --- |
| **MSTG/003 — [Mustang Firewall](https://github.com/mstg-sh/mustang-firewall)** | Local policy and visibility for coding-agent MCP traffic. |
| **MSTG/002 — [Mustang Swarm](https://github.com/mstg-sh/mustang-swarm)** | Run and compare coding agents on hardware you already own. |
| **MSTG/001 — Mustang Readiness** | SOC 2 readiness checks for small technical teams. In progress. |

## House rules

1. **Finished.** One problem, done properly.
2. **Runs where it can.** Your machine first.
3. **Free means usable.** Paying never unlocks the core product.
